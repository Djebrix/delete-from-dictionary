## The word

**inflammable**

One word, nothing else attached. It sounds like its own opposite — "not
flammable" — while meaning exactly the opposite: it burns. Deleting it from
the dictionary removes a word whose entire existence is a dangerous
misunderstanding, and the joke is in the word itself.

## How it works

`main.py` writes the single word to `/output/entry.txt` — exactly 11
characters, no trailing newline, no explanation. It self-checks the gate
(1–77 characters, one word, not only white space) and reads the file back to
confirm it holds exactly the word before exiting.

Run it locally:

```sh
OUTPUT_PATH=/tmp/entry.txt python3 main.py
```
